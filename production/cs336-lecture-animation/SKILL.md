# CS336 讲义动画

先找一个观众需要亲眼见到的变化，再决定画什么。交付时，观众能看片，下一位剪辑者能用同一时钟重画一镜、重拼成片。

## 接到任务先选入口

- **开新讲**：先读 [视觉宪法 v2](references/VISUAL_CONSTITUTION_v2.md)，再走 [Remotion 开工与交付](references/new-lecture.md)。以 `init_lecture.py … --renderer remotion` 创建工程；它会把 v2、色板、门禁和可运行的短片一并装好。正式分镜前，把本讲最难的一段替进样片。
- **修现片**：先定位正在看的**版本、实际 MP4 帧、镜内 cue**。锁住已验收的稿、音轨和时钟；既修改当前镜，也更新借它首尾姿态的镜或章门。未修改部分用原清片。读 v2 时确认这部片先前已明确批准的例外，写在本集定版记录，不抄成下部作品的默认值。
- **按 L12 定版复现**：走 [L12 固定版复现](references/l12-replay.md)。保留原 Cairo、帧表、首章门与旧素材入口，不拿新讲规范回改已经锁定的版式。
- **有人声/配乐才读** [声音与实录帧钟](references/voice-and-mix.md)；已有批准配音、音乐和授权即可重混，不先重生成。
- **第一轮画面方向有疑问**：用 [L12、L15 和《压缩即智能》对照案册](references/shot-study.md) 找同类动作和失败帧。借同一物件如何传递意思，不借别人的素材贴皮。

## 开工四件事

1. **先核事实，再排第一场。** 读讲义和原论文/数据/代码，记录来源、版本、单位、原值与推导。早段让一个具体例子卡住，问句留给真的转折。科普改错保留作者原来的语气。
2. **画一个会动的主装置。** 同一对象连续承载 2–4 个意群；在视觉上给它一次操作、一次结果。正文纯黑；无字的几何数据体用实心亮色，载字的用通透琉璃配白字。用位置和留白分组，正文只保留 v2 白名单中的字。不用「第 X 笔账」、标题卡、装饰线或 3D 模型盒填空。OP、疑问句之后的过渡段、END 除外，提问口播和接下来的正文不豁免。
3. **先锁声音，再锁动画。** 首问后接 5 秒 OP，OP 尾开入 Act 1；之后才有「口播问句 → 4 秒章门 → 正文首帧」。跨无关装置留 0.4 秒净空，别让旧字和新字拼在一帧。数值和高亮踩真实词首 ±150ms；4.5 秒公式预测与 6.5–7.5 秒多行 A/B 要分开记，两种都用显眼金色圆弧。不给静音算例编第二条时钟。
4. **把门禁跑在渲染前，把眼睛放在成片上。** 跑 `node scripts/lint-visuals.mjs`（正式有声片加 `--release`），0 errors 才合片。实际看开头、每个改过的接点中间、密文字、算例和片尾；再从交付 ZIP 无清片回编受影响的镜和真实接点。正片、母版、源码和配乐是不同交付；是否公开和哪条声音可外发，按用户授权。

优先产出用户当前要的东西。一镜试讲、上集成片、旧版复剪、封面和外部发布是不同的工作。

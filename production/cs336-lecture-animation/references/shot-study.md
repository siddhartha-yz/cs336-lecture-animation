# 三部实片怎么取法

**优先重看动的那 5–15 秒，再看源码。** L12 教怎么组织问句、镜头和复剪；L15 上集教怎么把声音、物件和真实帧锁在一起；《压缩即智能》教如何用一件几何装置做完证明。借原片的做法；新片的配色、排版和例外仍以 [v2](VISUAL_CONSTITUTION_v2.md) 为准。不要顺带照搬原片个别段落的暗灰底。

**做新镜头时沿用角色色，而不是抽一张原片调色。** 原片 27:14 的青色通道在下，金色信息面积覆盖在上，白边只分清相邻的数据体。L15 07:46 的金色表示被选中的 B 组，不是泛用的「重点色」；其它样本留在原格位。先从本讲定两到四种信号色，再定哪些量是宽、长、位置或面积。对同一变量，条、圈点和公式里的对应项保持同色。通透载字块默认白字，不让深色墨挤进亮度不够的色面。

焦点切换和分布变化是两种动作。`StackedProbDistribution` 的重排按概率重新分宽；`highlight` 只改变显著性，源码里的非焦点默认 0.35 不照抄，新片用 v2 的 0.14–0.22。13:47 的格子让所选层读得清，别层还够看出上下对应。同理，打包掩码选中 B₂ 时，先压暗兄弟行，不能为了新构图移动格位；到右侧只画这一行真的算出的 0.5。狭窄条上塞不下读数，把读数挪到条外，别一起缩成小字。

**把机位放在关系上。** 08:50 的整排格需要先按能看清二进制的尺度立住；焦点一到，没选的格减显著性，机位不回到全黑重新建图。L15 07:31 的纸面在矩阵右边留下可读宽度，07:46 这个位置让给同一行的柱。这不是左中右功能栏：右半画面只在有新证据时进入。最先试的造型选一张两区联动的稳定帧，再拉出真实运动中间帧校形、校字。

**面积证明只动一条边。** L15 的蓝/金两块占同一条概率轴：唯一可动分界是 `left + width * p`，左右宽从一处算，总宽始终代表 1。真实镜头从 0.80/0.20 移到 0.25/0.75，用 1.57 秒；高度 2 和 8 不动，下面的求和从 3.2 连续到 6.5。截图 08:53 的 3.8 只是中途截面。重做同类镜，先验两个端值，再暂停在中间核「边界位置、宽度数、各项颜色、总面积」是否同时说的是同一刻；别给两块各自补关键帧。

## 2. 复用章节语法，不照搬 L12 的章卡数

L12 实际顺序是 **首问落音 → 01:35.900 OP 五秒 → 01:40.900 第一门四秒 → 01:44.900 蓝色真实柱图**。后面五个门也先留问句，字在终点前退尽，到末尾约 0.45 秒才开下镜。开门的几何来自要去的地方：柱图用基线，信封/真实 issue 用对象上的点。不是每门都重复同一个全屏模板。

L15 也先听到首问；首问尾附近的单音铃落在已选 take 的尾音 +0.15 秒。**00:56.783 OP → 01:01.783 直接入论文切面**。中间第一章卡曾把“看两张文字卡”拖到八秒，定版取消；从约 04:43.900、08:07.150、13:00.350 起保留后面三张 4 秒门。镜头的真正入口由同一个下一镜函数算，不造一个缩略转场截图。如复现 L12，原有第一门也照原样留着。

**章门之外不做“第几笔账”。** 环节靠同一个物件移动或换焦点；不把冷开、数例、章节之间的普通接头变成 PPT 标题页。OP、问句后的过渡、END 是明确的装帧例外，不能把正文镜改名为章卡来逃避门禁。

## 4. 为什么新讲选 Remotion

决定性的好处是**画面按帧取状态，Studio、单镜和导出从同一份整数镜表读**。能直接定位某个错帧，重画本镜和它真正的接点，把其余清片继续用。这样字体、灰线、语音触发和工程装配能独立改、一起验；画面好看仍来自选例、构图和物件变化，不是 JSX 语言替你做决定。

- **沿用 L12 的接口意义**：定版重播用旧工程；无声清片、可切字幕、当前批准母版独立分发。编码器不同的近邻切片可能 PTS 正常、DTS 却重复；检查实际包和完整解码，不能只看时间总和。
- **沿用 L15 的实测路径**：ZIP 排除 38 条预渲片，安装锁定依赖，60fps 画全部 38 镜，再接同版 48kHz 双轨，恢复 62,284 帧、五章、313 字幕，全量解码；本机这次四 lane 约 26 分钟。不同机器的并行数先测，不必把这个吞吐写成承诺。
- **能机器判就前置，能人判就看成片**：字数、字体 cmap、时间窗、段类之间的关系和色板交给门禁；两件真实物体是否争视线、同色是否讲同一个量、像不像屏幕卡片、词是否念自然，看片/听片才能判断。验收时挑一张「用户最可能暂停截下来」的稳定帧，再挑一张「形变/交接最危险」的中间帧。

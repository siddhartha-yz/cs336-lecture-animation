# 从一支能播放的 Remotion 样片开工

```bash
SKILL="${CODEX_HOME:-$HOME/.codex}/skills/cs336-lecture-animation"
python3 "$SKILL/scripts/init_lecture.py" work/lecture-new --renderer remotion --lecture 16 --title '先用一个具体片名'
cd work/lecture-new
npm ci
node scripts/lint-visuals.mjs
npm run studio -- --port=3096
```

在 `http://127.0.0.1:3096/Lecture` 开整条；**Shots** 切到单镜。39.25 秒的「同加一个数」是模板的真实画面，不带旁白：先在分数台动手，再用同一组分数的 PyTorch 读数验算。机器已缓存依赖可用 `npm ci --offline`。本模板用 L15 实际跑过的 Remotion 4.0.534、Chrome/Chromium、FFmpeg/ffprobe 和 `fc-scan`；脚本复用本机浏览器，非标准路径设 `REMOTION_BROWSER`。不同机器先试一镜，别先开整片或叠一套 Manim 作底层。

原 `init_lecture.py 工程目录` 仍创建旧 Cairo 样片，供已有调用延续；**新讲明确用 `--renderer remotion`**。L12 定版回装入口和授权不变。

## 先做能暴露问题的 8–20 秒

挑一个观众看完能预测下一帧的机制，而不是概念简介。填这几项再写动画：

| 要定什么 | 记录什么 |
| --- | --- |
| 叙事 | 前 15 秒哪件事卡住；本幕问什么；后面哪件东西真正回答它 |
| 主装置 | 哪个对象在相邻 2–4 句里不换；哪个量控制几何；哪里让出走廊给箭头和标签 |
| 画面来源 | `sources.md` 记论文页、数据行、语义、单位、算例原值和计算式；普通演示数字不要冒充榜单 |
| 音频 | `sub` 是实际显示稿，`tts` 单独处理读音；经批准的 take、实际词首、字幕边界、数字事件及音频真实长度 |
| 接点 | 同一装置 `carry`；无关装置 `reset`；正式章门 `gate`；纸面只放经核实的实际证据 |

在真正要交的 1080 画布上看一张稳定帧和两个运动中间帧，再缩到约 480px 宽看。装置太小先想能否把一个真实关系画成几何；不要围同一行文本再加外框、假样本或装饰线。宽高都要看，不能用轮廓框把过小数据“量成合格”。数理推导同时保留活的实数/几何和变化的符号，不让观众长时间猜白公式对应哪一项。取法见 [逐片对照案册](shot-study.md)。

## 字、声音、画面用一张帧表

- `src/data/cut.json` 包含整数镜长、`cues`、`captions: [[in,out,sub],…]`、`beats`（`cue, wordFrame, kind`）及计划停顿。镜内从零起，字幕左闭右开；全局帧是此前镜长之和。把 `wordFrame` 填自**已选 take**，不从字幕开始猜触发时刻。章号、时间戳、字幕格式由同一份 cut 生成。锁稿后 `npm run captions:check` 用分享版的 libass 实压逐条测字，超宽或换行侵入上方时按口播拆成单行，别缩字号。
- `src/story.ts` 的 `posesFor` 由帧决定画面；Scene 不靠浏览器计时器、录屏或先渲后贴。用 `Stage.data/glass/paper/text/countdown` 让类型、数量、颜色、材料和文字可被门禁读到；文字走固定 em 和仿射缩放。给稳定画面置 `stableFrames`，至少包含该镜最复杂或最窄的真实稳定状态。 真实 PDF/公式图用工程的 `plates.json` + `Stage.plate`，从原文件裁，门禁核位图没被拉大或变形。
- 盲测、微缩问答若靠文字对齐就能分组，不画大框。镜表填 `"layout": "sample-text"`，实际文字走 `Stage.text(…, 'sample')`，稳定帧挑两份答案均到齐、金弧还没开始的一帧。此类镜的占幅用编码后真实墨迹量，导出和 `review-frames` 都会查，不靠空矩形撑面积。
- 跨镜只传物件和状态。同物需要在上一镜尾和下一镜头占同一尺寸/位置；完全无关时，上一镜先退净，相邻黑头/尾共 24 帧。黑的是画面层，不用主动切断在说的旁白或删字幕。章卡标题退净，再从实际来源位置打开下一镜第 0 帧；这帧必须已有可见正文，不再从黑渐入。源门禁比对末帧与该原生姿态；成片复核还能抓到忘记重画相邻镜的旧清片。
- 遮挡检查不能只看摆好的帧：数学弧线画在独立通道；天平倾斜时用扫过的范围判标签；模型压扁前先让内部字退场 0.25 秒。汉字整字上浮，多字排成整句时用统一基线和包含标点的真实 advance。字幕出来后，推导或回顾的第一件物件应已进画面；普通讲解中不另留长黑，已声明的净切除外。

## 从小修到可复剪成片

审片反馈只给了时间时，先用**同一版**镜表定位。`python3 "$SKILL/scripts/locate_feedback.py" src/data/cut.json 04:17.250` 报镜号、镜内帧、字幕和前后词锚；已有全片帧就传 `'#帧号'`。看过真实坏帧再改。

```bash
npm run still -- shift build/shift.png --frame=80
npm run render:shots -- shift --with-joins --replace
npm run sidecars
```

`--with-joins` 更新声明引用其首/尾姿态的镜。共享的画法、字体或图板改变时，按实际引用范围补渲；不能拿时间轴没变当作画面没变。已有批准的人声可从对应双轨母版原样抽 AAC 接回。固定采样率 48kHz、视频整数帧与轨道长度一致。配乐已成熟时，勿通过重生成来修局部响度。

**交付前：**

1. 跑项目根目录下的 `node scripts/lint-visuals.mjs`。有声正式片用 `--release` 核干声和实际长度。用户只要样片、无声图层或修一个镜时，采用该范围的验收；不把示范片发布为完整课。
2. 用 `node scripts/review-frames.mjs 实际成片.mp4 --ids=镜号,镜号` 抽帧、验净空，再看每处新接点前、中、后与手机宽度。共享同姿和新装置清场分开验；检查“先有字再有座位”与“旧字淡没才到达”的区别。看声音之外声音间隙、读题、静默、最后 3.5–4 秒音乐落点。程序通过不是手机能看清的证据。
3. `npm run export -- master` 产两轨母版加软字幕；`npm run export -- share` 产压印分享版；`npm run export -- silent` 拼无声音画素材。导出查分辨率、fps、Rec.709、每条有效帧及 PTS/DTS、章节、音轨和字幕。只交当前要求的版本。
4. 用 `python3 scripts/pack-edit.py build/edit.zip` 取源码、可用视觉素材、依赖锁和已生成的副件；加 `--shots build/native-shots` 才带原生清片。另开目录从真实 ZIP 取源及资产，排除预渲片，能重画涉及的接点与单镜；用导出命令拼全时间轴。声音全锁的复现从对应双轨取 AAC；不把参考声、声纹码、干声文件、私库、浏览器/仓库凭据打进源包。若需要验证“从零复剪全片”，用无视频缓存的纯源实际重画，不以已有切片拼接代替。
5. 封面优先从终稿选一个能讲出含义的几何帧，片名字重克制；看 1920×1080 与 320×180。向平台发布要有当前授权，不仅凭本地看片通过。

L15 同一版源包实测四 lane 38 镜 1080p60 全部重画并全解，证据与旧工程的取舍见 [案册](shot-study.md)。机器吞吐按实际测一镜估算。不能拿 L12 的时长、码率、字幕数或音乐版权作为新片默认。

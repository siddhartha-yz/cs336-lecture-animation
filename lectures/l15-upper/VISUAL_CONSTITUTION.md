## 铁律 1：色彩物理学（高饱和纯色发光体，严禁保守灰暗）

1. **画布底色唯一合法值：`#000000`（纯黑）。**
   - 严禁使用 `#09090b`、`#0f172a`、`#111827`、`#18181b`、`#1e293b` 等一切深灰/灰蓝/藏青背景或渐变底纹。
   - 仅当需要表达“真实世界纸面文献/论文节选/代码卡”时（每 5–6 分钟最多 1 次），允许使用浅米白 `#F2F1EC` 卡片。
2. **禁止灰暗莫兰迪色，主元素必须高饱和实心着色：**
   仅允许从以下色板取色（严格对应《压缩即智能》实测色域）：
   - 纯白主字/公式/细分隔线：`#FFFFFF`
   - 辅助坐标/刻度线：`#666666`（严禁用于大面积色块或正文）
   - 电光青蓝（概率柱、左分支、基础宽条）：`#19B5FE` / `#29ABCA` / `#58C4DD`
   - 亮金明黄（面积证明、高光公式、核心强调）：`#FFD43B` / `#F5C731` / `#FFFF00`
   - 翡翠亮绿（概率饼盘、右分支、通过状态）：`#2EC492` / `#3DDC84` / `#5CD0B3`
   - 炽橙→珊瑚红→热洋红序列（对比柱、码长阶梯、警示）：`#F25C3B` → `#E84C5C` → `#DF5296` → `#F462C0`
   - 高亮紫（辅助对比维度）：`#B87BFF`
   - 术语单行注记（全片唯一允许的中灰文字）：`#B0B8C4`
3. **实体厚重感规则：**
   - 核心柱状图、概率宽条、面积块、前缀树区块必须使用**高不透明度实心填充（`fillOpacity: 0.78 ~ 1.0`）+ 锐利 `1px–1.5px #FFFFFF` 边框分隔**（参考《压缩即智能》码长阶梯与面积图）。
   - 仅当两层图形重叠透视（如积分阴影、剪刀口误差区）时，使用 `fillOpacity: 0.28 ~ 0.45`。
   - 严禁全屏都是 `1px` 空心暗线框。
4. **聚光靠压暗背景，绝不靠调灰主角：**
   - 聚焦某一区块/分支时，主角保持 100% 饱和度与 `opacity: 1.0`；非聚焦兄弟元素压低至 `opacity: 0.14 ~ 0.22`（或叠加暗沉禁止态遮罩），形成强烈戏剧反差。

## 铁律 2：反 PPT 空间架构（活数学舞台，严禁幻灯片模板）

1. **绝对禁止以下“PPT / SaaS 仪表盘”结构（出现即打回）：**
   - ❌ 严禁 `border-radius >= 4px` 的圆角矩形卡片、药丸标签（Pill Badges）、毛玻璃（backdrop-blur）、阴影浮层（box-shadow）。
   - ❌ 严禁“顶部标题栏 + 副标题 + 左中右三栏卡片 + 底部总结横幅”的网页/PPT 布局。
   - ❌ 严禁流程编号徽章（如 `Stage 01`、`Step 1`、`01 / 02 / 03`、`Phase A` 装饰角标）。
   - ❌ 严禁抽象占位图标（如“带三条横线的纸张图标”代表文档、齿轮代表算法）；必须渲染**真实微缩数据**（真实词元、真实概率小数、真实二进制串、真实 3–5 行代码）。
2. **核心数学装置统治法则（65%–85% 视觉占空）：**
   - 每一幕的核心只能有一个**巨幅、精密、可计算的数学/工程装置**（如矩阵、坐标系、宽度代表概率的堆叠条、真实词元序列+实时仪表盘）。
   - 装置必须像《压缩即智能》的二进制树或字母概率墙一样直接长在纯黑画布上，**不套任何外层大面板框**。
3. **连续舞台演化（禁止翻页感）：**
   - 相邻 2–4 个口播段落必须复用同一个数学装置，通过**局部放大、增加一行公式、拉动参数滑块、切分色块、压暗旧项亮起新项**完成推演；绝不为每一句话清屏重绘一张新幻灯片。
   - 只有跨越无关章节或彻底更换心智模型时，才执行 `0.4s` 彻底清空画布再进新装置（严禁两个密集画面交叉叠影 cross-fade）。
4. **图形内嵌公式：**
   - 凡是涉及面积、占比、分段求和的公式，优先将几何形态与公式对齐（例如把概率条宽度直接对齐下方符号、把微小几何剪影直接放进等式项中，减少文字解释）。

## 铁律 3：文字极简主义（彻底根除“意义不明的说明文字”）

1. **零复述原则（最高红线）：**
   - 屏幕绝不是旁白的提词器或笔记摘要。**凡是口播已经说出来的逻辑、解释、结论，严禁在屏幕上再印成中文说明框、侧边注释段或底部总结条。**
2. **屏幕文字四类白名单（白名单以外的文字一律删掉）：**
   - ① **公式与实时跳动数字：** 如 `4.19 bits`、`KL = 0.105`、`-\log_2(p)`。
   - ② **极短结构锚点（1–4 个词，无句号）：** 如 `Naive` / `Optimized`、`Total width = 1`、`Prompt` / `Response`、`显存上限`。
   - ③ **真实原始数据样本：** 如真实的中文对话片段、真实 Python 代码、真实二进制串、真实词元格。
   - ④ **新术语单行注记（可选，严格限 1 行 ≤ 16 字，无边框 `#B0B8C4`）：** 仅在首次引入生僻术语时贴在术语正下方，停留 ≥ 4 秒后自然退场。
3. **硬字数红线（静态预算）：**
   - 扣除底部主字幕与“真实代码/对话样本”后，**同一帧画面中出现的非公式中文说明文字总量严禁超过 20 个汉字**，且绝对禁止出现超过 12 个字的完整陈述句（除大幕核心问句外）。
4. **彻底封杀 AI 免责词与内部元数据（全局零容忍）：**
   - 严禁出现任何以下字样及变体：
     `教学示意`、`教学算例`、`教学例`、`读图约值`、`示意图形`、`不按比例`、`核心结论`、`本节小结`、`关键洞察`、`来源口径`、`复剪包`、`讲义图`、`Slide`、`课堂举例`。
   - 仅在引用真实论文图/数据时，于右下或左下角用极小宋体标注纯净出处（如 `Ouyang et al., 2022`）。
5. **字体规范：**
   - 中文统一 `Noto Serif CJK SC`（宋体）；数学符号与英文标签统一 `Latin Modern / Computer Modern`；仅代码、词元串、二进制序列使用细等宽字体。禁用粗黑无衬线 PPT 标题体。

## 铁律 4：动效即证明 & 音频驱动时钟

1. **禁止“无声默片算例”：**
   - 严禁代码 Agent 擅自插入没有口播配合的 8–20 秒静音推导页。所有数值跳变必须踩在对应口播关键词 `±150ms` 内；无声停顿仅限两种情况：① 关键结论后 `1.2s–1.8s` 呼吸留白（配合 `1.00 -> 1.03` 极轻推镜）；② 明确策划的 `4.5s` 观众互动盲测/思考题。
2. **四维联动玩具（Live Apparatus）：**
   - 展示函数或指标关系时（如 Sigmoid、KL、DPO 梯度权重），必须建立**单参数驱动的多组件联动**：一个数值变化，曲线动点、顶部公式实时数字、柱状图高度、饼盘扇形面积在同一帧精确同步响应。
3. **转场与排版防穿帮：**
   - 禁止插值 `fontSize` 做缩放（一律走 `transform: scale()` 矩阵变换防抖动）。
   - 容器缩放/变形前 `0.25s` 提前淡出内部文字，严禁文字被非等比压扁。
   - 底部公式与标签距字幕顶边至少留白 `40px`；坐标轴数字距轴线/曲线偏移 `12–16px`。

## 铁律 5：画面站得住，文字看得清

1. **主装置占幅。** 正文稳定帧只留一个主装置，其包围盒占字幕以上安全区约 60%–80%；通常横向撑到画幅的 68%–80%，纵向 55%–70%。用词元位置、概率面积、层高或真实样本填出关系，不靠外框、装饰线或放大空白。介绍数据集时，优先直接排 4–6 行可溯源的样本或真实分组；有明确当前项时，其余项压到 0.18，露出够辨认的形状。
2. **彩色容器配字。** 文本容器只有亮黄 `#FFD43B`、浅青 `#58C4DD` 实心块可配纯黑字 `#000000`；蓝、绿、红、紫、橙等改用 0.30–0.42 的同色通透填充、约 2 px 高饱和描边和纯白字 `#FFFFFF`。面积、概率、显存等数量本体仍用原来的实心色；文字放到读得清的一侧。纸面引用用黑墨。
3. **模型用平面结构。** 网络模型和显存块不得用等轴测盒。用锐边平面矩形、少量层纹或不超过两道轻微的二维层叠，按 1080p 计，内部文字距四边至少 20 px。层高较薄时，标签移到侧边，用短引线标清实际层位。
4. **字号、行距、功能线。** 按 1080p 计，坐标刻度、模型副标、角标至少 20 px，学术出处至少 18 px；多行对比正文用 1.45–1.55 倍行距，段落编号之间另留呼吸。下划线只用作定位、读数或证明的一部分；抽出公式项时留透明虚线空槽，不贴色块盖字。

OP、问句后的过门与 END 沿用本片例外。后续 DPO 下集制作也沿用本条。

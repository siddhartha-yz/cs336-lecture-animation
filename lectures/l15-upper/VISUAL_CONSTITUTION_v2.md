# VISUAL_CONSTITUTION v2（《压缩即智能》级视觉、动效与音画硬约束）

本文件为项目最高优先级工程规范。适用于所有视频脚本编写、Remotion / Manim 场景代码生成、TTS 文本校验与 Stable Audio 3 配乐混音。任何新建或修改的产物若违反以下任一条款，视为构建失败，必须返工重写。

**例外：OP、疑问句之后的过渡段和 END 除外。豁免只覆盖这三类段落本身，不延伸到提问口播或随后的正文。**

---

## 铁律 1：色彩与双轨材质物理学（高饱和发光体，严禁灰暗脏字）

1. **画布底色唯一合法值：`#000000`（纯黑）。**
   - 严禁使用 `#09090b`、`#0f172a`、`#111827`、`#18181b`、`#1e293b` 等深灰/灰蓝/藏青底色或背景渐变、背景网格。
   - **唯一例外（Layer 2 真实文献切面）：** 每 5 到 6 分钟最多切入 1 次浅米白 `#F2F1EC` 卡片（`1px #C8C6BE` 细框），仅用于呈现真实论文节选、原始图谱或 PyTorch 核心代码片段。严禁出现讲义图号，仅在右下角用 $\ge 18\text{px}$ 低调宋体标注纯净学术出处（如 `Ouyang et al., 2022`）。

2. **唯一合法色板（严格锁死于 `src/theme/palette.ts`，禁止场景内硬编码灰暗色）：**
   ```ts
   export const PALETTE = {
     bg: '#000000',
     paper: '#F2F1EC',
     white: '#FFFFFF',
     axis: '#666666',      // 仅用于坐标轴与刻度细线，严禁用于大面积色块或正文
     gloss: '#B0B8C4',     // 仅用于新术语单行注记
     cyan: '#19B5FE',
     blue: '#29ABCA',
     lightCyan: '#58C4DD',
     gold: '#FFD43B',
     yellow: '#FFFF00',
     green: '#2EC492',
     orange: '#F25C3B',
     coral: '#E84C5C',
     magenta: '#DF5296',
     pink: '#F462C0',
     purple: '#B87BFF',
   } as const;
   ```

3. **双轨材质铁律（彻底解决“实心 vs 通透”冲突与“黑字压暗块”脏感）：**
   - **A 类 · 纯几何数据体（块内无中文或仅有极简数字/符号）：** 如柱状图、概率宽条、面积证明块、码长阶梯、二进制树网格。必须使用 **高不透明度实心填充（`fillOpacity: 0.78 ~ 1.0`）+ 锐利 `1px ~ 1.5px #FFFFFF` 边框分隔**，还原《压缩即智能》的彩色玻璃发光质感。
   - **B 类 · 载字结构容器（块内含中文或模型/词元标签）：** 如模型块、词元格、沙箱窗口、对话块。强制使用 **通透琉璃填充（`fillOpacity: 0.30 ~ 0.42`）+ `2px` 高饱和描边 + 纯白文字 `#FFFFFF`**。
   - **配字明度红线：** 仅高明度亮黄 `#FFD43B`、亮青 `#58C4DD` 实心块上允许使用纯黑字 `#000000`；深蓝、翠绿、珊瑚红、紫色、深橙色块上 **绝对禁止使用黑色文字**。
   - **透明透视叠层：** 两层图形交叠区（如奖励黑客剪刀口、积分阴影）使用 `fillOpacity: 0.28 ~ 0.40`。

4. **聚光机制：**
   - 聚焦某一分支或数据项时，主角保持 `100%` 饱和度与 `opacity: 1.0`；非聚焦兄弟项统一压暗至 `opacity: 0.14 ~ 0.22`，绝不通过把主角调灰来制造“克制感”。

## 铁律 2：反 PPT 空间架构与反“极简空洞”补丁

1. **严禁以下 PPT / SaaS 仪表盘元素（命中即打回）：**
   - 严禁 `border-radius >= 4px` 的圆角卡片、药丸标签（Pill Badges）、毛玻璃（`backdrop-filter`）、浮层阴影（`box-shadow`）。
   - 严禁“顶栏大标题 + 副标题 + 左中右三栏卡片 + 底部总结横幅”的幻灯片布局。
   - 严禁流程编号徽章（`Stage 01`、`Step 1`、`01 / 02 / 03`、`Phase A`）与无功能装饰短横线（如孤立词组或字母 `A / B` 底下无意义的短线）。
   - 严禁抽象占位图标（如画三条横线代表文档、画齿轮代表算法）；必须渲染 **真实微缩数据**（真实中文对话、真实词元、真实概率小数、真实 Python / PyTorch 代码）。

2. **废除复古 3D 立方体：**
   - 除非讲真正的三维数学空间，严禁使用等轴测 3D 盒子表现神经网络模型或显存块。统一改用 **现代扁平锐利矩形结构块**（可用内部极细等距横线表现网络层，或用清晰间距的 2D 叠层表现梯度/优化器开销），内部文字四边留白 $\ge 20\text{px}$。

3. **视觉占空底线（治“85% 纯黑孤岛病”）：**
   - 正式讲解帧的核心数学/工程装置包围盒，必须占据安全区（扣除底部字幕）宽度的 **65% ~ 80%**、高度的 **55% ~ 75%**。
   - 严禁将 2 个短词或 4 个小格缩在画布中央、留出大面积纯黑空地。展示单一概念或数据集时，优先铺开 **4 到 6 行真实微缩样本阵列**，仅高亮当前讲述的 1 行，其余压暗至 `opacity: 0.18` 构成视觉背景语境。

4. **连续舞台演化与“双区联动”数学推导法则：**
   - 相邻 2 到 4 个口播段落必须复用同一个核心装置，通过推镜放大、增删公式项、滑块联动、局部高亮推进叙事；跨无关场景才执行 `0.4s` 彻底清空画布（严禁两个高密度画面 cross-fade 叠影）。
   - **重推导篇强制双区联动：** 在高密度数学推导段落（如 DPO 闭式推导、梯度链式法则），严禁出现超过 `25s` 的“纯黑屏 + 纯白 LaTeX 独角戏”。屏幕必须维持 **“左侧/下方实时数值或几何装置（如 3 句迷你概率柱、切线函数图、实时误差滑块）+ 右侧/上方符号变形”** 的同步联动，做到动效即证明。

## 铁律 3：文字极简主义、字号底线与零水印红线

1. **零复述红线：**
   - 屏幕绝不是旁白的提词器或笔记摘要。凡是口播已讲出的解释、因果和总结，严禁在屏幕上再印成中文说明段、侧边注释盒或底部结论条。

2. **屏幕文字四类唯一白名单（白名单外一律删除）：**
   - **公式与实时跳动数值：** 如 `KL = 0.040`、`4.19 bits`、`$-\log_2(p)$`。
   - **极短结构锚点（1 到 4 个词，无句号）：** 如 `Prompt`、`Response`、`显存上限`、`Pass@1`。
   - **真实原始数据样本：** 真实微缩问答对、真实代码、真实词元序列。
   - **新术语单行注记（可选，限 1 行 $\le 16$ 字，无边框 `#B0B8C4`）：** 仅在首次引入生僻术语时置于术语正下方，停留 $\ge 4.0\text{s}$ 后自然退场。

3. **单帧字数硬预算：**
   - 扣除底部主字幕与“真实代码/对话样本”后，**同一帧画面中非公式中文说明文字总量严禁超过 20 个汉字**，且禁止出现超过 12 个字的完整陈述句（大幕核心提问除外）。

4. **字体、字号底线与缺字预检（1080p 画布基准）：**
   - 中文统一 `Noto Serif CJK SC`（宋体）；数学符号与英文标签统一 `Latin Modern / Computer Modern`；薄等宽字体仅限代码、终端日志与词元流。
   - **最小字号底线：** 坐标轴刻度、模型副标签与角标绝对不小于 `20px`；学术出处角标不小于 `18px`；多行对比文本行距锁定 `lineHeight: 1.45 ~ 1.55`。
   - **缺字零容忍：** 渲染前必须校验所有中文字符串均落入所选字体字库，严禁成片出现 `□` 豆腐块。

5. **AI 防御水印与内部元数据零容忍黑名单：**
   - 全局禁止出现以下字样及任何变体：
     `教学示意`、`教学算例`、`教学例`、`读图约值`、`示意图形`、`不按比例`、`核心结论`、`本节小结`、`关键洞察`、`来源口径`、`复剪包`、`讲义`、`课程幻灯`、`课堂举例`、`Slide`。

## 铁律 4：动效几何避让、防穿帮与时钟纪律

1. **彻底禁止对汉字使用 `Write` 描边动画：**
   - 复杂汉字用矢量路径 `Write` 极易在中间帧碎裂抖动。**所有中文标题、章卡、短标签一律改用交错上浮 `FadeIn(shift=UP*0.15, lag_ratio=0.04, duration=0.45s)`**。
   - `Write` 仅限英文短缩写（如 `SFT`、`DPO`）与 LaTeX 公式（上限 `min(0.65s, remaining - 1.5s)`）。

2. **缩放防抖与变形保护：**
   - 严禁插值 `fontSize` 做缩放（一律走纯浮点 `transform: scale()` 矩阵变换）。
   - 容器执行非等比缩放/形变前 `0.25s` 提前淡出内部文字，杜绝文字压扁或重叠。
   - 隐藏或抽离公式中的某一项时（如抽离 `$r(x,y)$`），使用 **透明内空 + 亮金色虚线框（`dashed #FFD43B`）**，严禁贴不透明实心色块“打码”。

3. **严格几何避让：**
   - 底部字幕安全区为 `y: 930 ~ 1060px`，所有公式与底部标签距字幕顶边留白 $\ge 40\text{px}$；坐标刻度距轴线与曲线偏移 `12 ~ 16px`。
   - **跨节点弧线/箭头：** 必须走独立上方或侧方净空通道，严禁贯穿下方的数字行、权重行或公式。
   - **动态倾斜构件（如天平横梁）：** 旋转扫描路径内禁止放置静态文字或公式，防止劈字。

4. **音频驱动时间轴（严禁“无声默片算例”）：**
   - 严禁代码 Agent 擅自插入没有口播配合的静音数值演示页。**除以下白名单外，全片任何无声片段超过 `2.2s` 视为构建失败**：
     - 5 秒全局总片头（总片头结束后 **直接切入 Act 1**，不连播第一章文字卡；内部 4 秒章卡仅从 Act 2 起用）；
     - 关键反转或核心公式揭晓后的 `1.2s ~ 1.8s` 呼吸留白（静止超 `1.8s` 必须叠 `1.00 -> 1.03` 极轻推镜）；
     - 明确策划的观众思考/盲测静默：**极简公式预测题 `4.5s`**，**多行代码/文本 A/B 盲测 `6.5s ~ 7.5s`**，且必须在底部中央挂载高可见度的 **金色圆弧进度计时器**（严禁隐蔽细灰圈）。
   - 所有数值跳变与高光触发必须踩在对应口播关键词 $\pm 150\text{ms}$ 内；状态故障演示（如模式崩溃）停留时间不低于 `3.5s`。

## 铁律 5：口播脚本、节奏与 TTS 排雷规范

1. **按内容属性定长，拒绝注水凑数：**
   - **动机与工程篇**（如 L15 上集）：**16 ~ 20 分钟**，凌厉紧实，先把工程痛点和直觉冲突打穿。
   - **硬核数理推导篇**（如 L15 下集 DPO）：**22 ~ 26 分钟**，零跳步，所有超出大一微积分/线代/概率论的工具全部现场搭桥，但不必在屏幕上刻意印出“大一数学”字样。
   - 原生语速目标锁定 `230 ~ 250` 字/分钟，`speed_clamp = [0.97, 1.04]`。

2. **冷静幽默语感与跨幕案例互斥：**
   - 语气锁定 **“冷静幽默 + 同行在黑板前聊天”**；严禁网络快餐烂梗，严禁“不是……而是……”对称 AI 腔。
   - **案例互斥铁律：** 前半段讲解用过的具体代码题或问答例，严禁在后半段观众盲测/思考题中重复出现，防止剧透。

3. **实战 TTS 高危排雷词表（`tts` 字段强制执行）：**
   - **禁止生造双字缩略词：** 如 `估抖`（听成孤岛）改为 `估不准` 或 `估值很容易抖动`。
   - **孤立同音/偏硬词必须补上下文或替换：** `沸水` 单独作为词元时写 `“沸水”这个词`（防听成废水）；`拒答` 写 `拒绝回答`；`老实给出` 写 `干脆给出` 或 `老老实实给出`；`卡在` 写 `拦在` 或 `堵在`（防误读 qiǎ）。
   - **复合数学词用逗号强制正确断句：** 如 `前缀和 cu_seqlens` 写作 `前缀和，也就是 C U seek lens`（防断成“前缀，和”）。
   - **禁止朗读 LaTeX 源码与裸下划线：** 绝不在口播出现 `字母 R 下标普赛`，字幕 `sub` 中也不允许出现 `r(y_w)` 裸下划线源码。
   - **符号与缩写全片读音唯一锁定：** 例如 `$\pi$` 全片统一写 `派`（严禁前后混读 `派/拍`）；`G-V` 写 `G，V，` 加微停顿防连读发糊；长句分号全改逗号或句号。
   - **情绪分层路由：** 保持同一说话人切片库（`E1` 悬念升调 / `E2` 轻快互动 / `E3` 清晰讲解 / `E4` 锋利反转 / `E5` 沉静收束）；全部大幕核心提问（以 `吗？`/`呢？` 收尾）与高潮反转锚点句采用 `N=4` 候选人工精挑。

## 铁律 6：配乐生成（Stable Audio 3）与母带混音规范

1. **生成标准 SOP：**
   - 每条乐章提示词必须携带 `TrackType: Music, VocalType: Instrumental` 前缀，全片所有乐章锁死同一关系大小调（如 `D minor / F major`），保证幕间 `2.5s` 等功率交叉淡变严丝合缝。
   - **强制两段式工作流：** 每轨先抽 **`30s x 3` 个随机种子试听**，人工确认无跑调、无乱入人声、无过猛鼓点后，再锁定优胜种子直接整段生成完整时长（严禁 30 秒拼接循环）。

2. **“冷静理科张力”提示词黑白名单（专治预告片大鼓与葬礼悲情片）：**
   - **严禁触发词（黑名单）：** `Cinematic Tension`, `Trailer Hits`, `Riser`, `Whoosh`, `Pulsing Sub Synth`, `Spiccato`, `Brooding`, `Solemn`, `Weeping Cello`, `Dramatic Brass`。
   - **推荐织体（白名单）：** 需要系统压力或反转张力时，使用 `96 ~ 102 BPM` 的 **稳态八分音符弱音钢琴 + 低音马林巴固定音型（ostinato）+ 平稳低音衬底**，保持客观、紧凑、不煽情。

3. **防后段爬升与动态混音参数：**
   - **响度基准：** 人声总线 `-16 LUFS`；BGM 基准 `-33 ~ -34 LUFS`。
   - **防长轨后段自发抢戏（必查）：** Stable Audio 3 在 2 分钟后常自发加厚编曲或推亮敲击。混音脚本必须每 `30s` 扫描短时响度，凡后段比前段爬升超 `+2.5 dB` 或出现密集鼓点/亮敲击时，自动压低 `-2.5 ~ -4.0 dB` 并轻切 `120 Hz` 以下低频。
   - **人声护航（EQ + 侧链）：** BGM 总线在 `1.8 kHz ~ 3.5 kHz` 挂宽 Q（`Q = 1.0`）`-2.5 ~ -3.5 dB` 凹槽（专治马林巴和电钢顶人声）；并挂温和人声触发侧链压限（衰减 `2.0 ~ 2.5 dB`，Attack `30ms`，Release `250ms`），使人声静默思考期音乐自然浮起托底。
   - **提问铃音与片尾余韵：** 提问前 `2s` 起平滑压乐 `-6 dB`，尾音 `+0.15s` 触发单音干爽铃音（截取前 `3.0 ~ 3.5s` 平滑淡出，混音 `-12 dB`）；全片最后一句旁白落音后，必须留足 **`3.5 ~ 4.0s`** 钢琴自然衰减尾音再收黑。

## 铁律 7：自动化验收门禁（`scripts/lint-visuals.mjs`）

每次生成或修改完场景，Agent **必须** 运行静态校验脚本并确认 `0 errors` 后才能交付：

1. **色值锁校验：** 扫描所有场景文件，禁止出现 `PALETTE` 之外的裸十六进制色值与 `slate- / zinc- / gray-800 / gray-900` 类名。
2. **PPT 样式拦截：** 扫描 `borderRadius >= 6`、`backdropFilter`、非 `#F2F1EC` 容器的 `boxShadow`、以及等轴测 3D 盒子组件调用，命中即报错。
3. **黑名单词库扫描：** 正则全局检索 `教学示意|教学算例|教学例|读图约值|不按比例|核心结论|本节小结|来源口径|复剪包|讲义|课程幻灯|课堂举例|Stage 0`，命中即报错。
4. **字数预算与动画校验：** 检查非字幕、非样本区域的中文单条长度（`> 18` 字警告）与单帧汉字总量（`> 20` 字报错）；检查是否存在对含中文节点调用 `Write` 动画；校验全量中文字符是否被目标字体覆盖（防 `□` 缺字）。
5. **静音死帧拦截：** 比对场景帧数与真实配音音频时长，凡不在白名单（片头/章卡/策划思考停顿）内且无声超过 `2.2s` 的片段，直接报错阻断。

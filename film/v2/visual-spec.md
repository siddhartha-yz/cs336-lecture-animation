# Spatial film contract

Pure black stage. Saturated active pigments: A cyan #39CDF2, B violet #BA7EFF, evidence gold #FFD448, success green #72E784, error coral #FF5B68, neutral warm stock and gray. Model = colored letter in open ink circle; selected item = cut gold slip; actual deliverable = folded paper with attached ink; candidate = node or observed point; tracks = hairlines. No bevel, reflective shading or colored backgrounds. The stills read as flat diagrams; perspective, occlusion and parallax reveal real spatial relations when helpful. Whole stage is continuous, with no corner labels, progress indicator or chapter banners. Key results get visual holds.

Write draw(g,i,t,duration) in actN.py. Rendering logical 1600×900: no important object below screen y=765. import `from spatial import *`. Use World(g,yaw=0,pitch=0,zoom=1,target=(0,0,0),distance=13,perspective=1). World coordinates x right, y up, z towards camera; origin projects to (800,404); default scale 128 px/unit. Positive pitch places camera above target; radians. Camera dimensions typically x ±5.8, y ±2.6, z ±3.6. Optional `center=(800,404)` kw camera center. Set camera at World construction. Depth-sorted 3D surfaces, arrows and annotations draw at end via w.draw().

Method contract:
- w.box(p,size,c=GOLD,alpha=1,rot=(0,0,0),label='',fill=.26,edge=1.1,label_size=30,label_color=None). p and size=(x,y,z), true thickness. rot XYZ Euler radians. alpha multiplies faces/outlines/label. fill is base brightness fraction. For plain cutout swatches use w.tile(p,label='',c=GOLD,size=(.96,.67,.14),rot=(0,0,0),alpha=1,fill=.33,label_size=31). For cut folded stock use w.paper(p,width,height,c=GOLD,alpha=1,rot=(0,0,0),fill=.74,cut=.23).
- w.disk(p,c,label='',r=.42,depth=.15,rot=(0,0,0),alpha=1,fill=.34,label_size=34), an open ink circle facing local +z.
- w.segment(a,b,c=MUTED,width=2,alpha=1,dash=None,sort_depth=None), w.path(points,c=MUTED,width=2,alpha=1,dash=None,arrow=False,progress=1); w.curve(p0,p1,p2,p3,c=MUTED,width=2,alpha=1,progress=1,arrow=False); all points tuples. 
- w.face(points,c=MUTED,alpha=1,fill=.18,edge=1.2); w.grid(p,nx,ny,spacing=.5,plane='xz',c=GRID,alpha=.65,width=1.12), p is center, nx/ny are number of cells, y increases on xy, z increases on xz.
- w.text(s,p,size=33,c=INK,alpha=1,align='center',font='serif',weight='normal',depth_bias=.015), Pango billboard kept upright; w.ink(s,p,plane,...) projects the type along its physical surface. w.dot(p,c=GOLD,r=.057,alpha=1); w.sphere(p,c=GOLD,r=.20,alpha=1); w.mark(p,ok=True,r=.14,alpha=1). 
- w.anchor(alpha=1,scale=1,p=(0,0,0)): exact common bookend, model rings A/B centered x=-2.45,+2.45 relative p (default origin), gold unlabeled thin tile at p. Default camera position/orientation at bookends. Connect mentally/visually to next beat, no blackout. 
- Helper `vlerp(a,b,u)`, `clamp`, `mix`, `step`, `ease`, `blend`, RGB constants, aliases A=BLUE, B=PURPLE. g.cue(phrase,fallback_fraction,occurrence=0) consumes normalized English index and returns fraction of full beat incl hold from audio; g.part(index,fallback_fraction) similar for bilingual phrase pair. Use `g.speech` seconds of spoken portion if positive; otherwise duration minus authored hold. For small fixtures preview tool `python3 work/v2/preview.py ACT BEAT FRACTION PATH`.
- Speaker script work/v2/actN.json = array {"parts": [["English", "Chinese"], ...], "hold": 1.7}; optional "spoken" complete English take for pronunciation and "title" English metadata only. No Chinese in picture apart from subtitles. First references studied separately; use original visual examples/geometry, no reuse of source frames.

Visual rhythm: each beat is a camera/action segment, not a slide. Advance/rescale/fold existing geometry as the point changes. Primary object should be easy to track even with narration muted. Shift viewpoint to unmask structure, then settle for 1.5–2s at a decisive reveal. Do not make a decorative orbit fight a data read.
